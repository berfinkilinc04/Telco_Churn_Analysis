# Telco_Churn_Analysis
An analysis of 7,000+ telco customers to uncover churn factors in fiber optic and short-term contract segments.

Key Findings
Contract Type: Month-to-month subscribers have a much higher churn rate (42.7%) than long-term users.  

Service Risk: Fiber Optic users are the most likely to leave (41.9%) despite being high-paying customers (~$90/month).  

Technical Support: Lack of tech support is a major driver for churn. Fiber users without support have a 49.4% churn rate, compared to only 22.6% for those with support.  

Tech Stack
Language: Python

Libraries: Pandas, Matplotlib, Seaborn

Environment: Google Colab

Recommendations
Encourage month-to-month users to switch to annual contracts through incentives.  

Offer Free VIP Tech Support to Fiber Optic customers to increase loyalty and reduce churn.
